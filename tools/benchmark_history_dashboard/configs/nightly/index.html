Dataflow Engine Nightly Benchmarks

Explore nightly benchmark runs for the Dataflow Engine, executed daily across various configurations.

Benchmark Categories

Note: For ongoing performance runs tracking incremental changes across builds, see Continuous Benchmarks .

  • ClickHouse Benchmarks — Combined throughput, CPU, and memory/resource trends for df_engine and the OpenTelemetry Collector.
  • Syslog Benchmarks — Performance runs for syslog ingestion and processing pipelines.
  • Backpressure Benchmarks — Evaluations focusing on flow control and load management.
  • Filter Benchmarks — Evaluations focused on filter processor measurements.
  • Batch Processor Benchmarks — Batch processor performance across logs, metrics, and traces with OTAP/OTLP baselines.
  • Saturation Benchmarks — Performance at saturation across different CPU configurations (1, 2, 4, 8, 16 cores).
  • Scaling Efficiency Benchmarks — Scaling efficiency ratios across multiple core counts.
  • Batch Size Variation Benchmarks — Standard load tests with varying input batch sizes (10 to 8192 records per request).
  • Syslog TCP Benchmarks — Syslog ingestion via TCP protocol.
  • Syslog TCP Benchmarks (OTel Collector) — Syslog TCP ingestion through the Go-based OTel Collector.

About Nightly Runs

Nightly benchmarks are scheduled performance evaluations designed to capture stability and scalability trends over time. Each configuration variant measures resource utilization under load.
